   <h2>Evaluate</h2>
   <br>
   <p>My initial design was for a website to take in inputted information from the user and give them recommendations based on their data and the added knowledge from the analysis I did on the dataset itself.<br>
      I wanted it to also give broad recommendations based on the analysis that I had done and for the
      data entered by the user to be saved as a JSON file and then converted to a CSV file because it is easier to use and navigate.<br>
      However, I realised that my goals were too unrealistic and that I would have to make them simpler.<br>
      I decided to output the entered data as a table, give broad recommendations to the user based on the dataset I analysed, and only save the entered data as a JSON file.</p>
   <br>
   <p>If I had more time, I would do more analysis on the dataset, find linear regression, connect each of the columns, and find more correlations between each column to see any further connections.<br>
      I would also include the columns 'ever_married', 'work_type',and 'Residence_type' since I believe it would make for a higher quality analysis on predicting strokes that would be of use for<br>
      a niche selection of people who have heart problems or have a family history with heart problems.</p>
